# Tracks (read this before the folder names confuse you)

Three different things have been called "goldeneye-native" or GEVR-adjacent:

1. **GEVR (this repo)** — native-track docs, XR tools, measurement helpers. MIT overlay.
2. **no6969el/goldeneye-native** — from-scratch native host + architecture docs. Separate repo.
3. **Playable native + GETV** — local bootable port with stereo work. Not published here yet (third-party renderer licence still open).
4. **cblock85/GoldenEye64Recomp** — recomp host. Historical VR path only. GPL-3.0. Never vendored into GEVR.
