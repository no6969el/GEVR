## The rules this session earned

**The wearer is the best instrument in this project.** Four faults were diagnosed from description alone — "rotation only is not free", "turn left and I see the right side of the gun" (a mirrored transform), "it's still attached to other parts" (the engine's turn-sway), and "closer brings it in front" (an inverted Z). **Ask what it looks like, not whether it works.** And when they say *where* it broke, revert to there first.

**When a changing thing misbehaves, freeze it.** The two-guns ghost survived every argument and died instantly to a constant: a constant can't feed back, mispair or oscillate, so whatever survives it isn't the fault.

**Measure, don't reason.** Four changes in a row on argument moved nothing; one logged line — `game=(10.9,−20.7,−33.4)` against `ours=(23.4,−6.4,+28.9)` — found an inverted sign immediately.

**Before writing off a fault as somebody else's, check whether its timing belongs to you.** Five bugchecks, each within a minute of a VR session ending, and a `-NoXr` session that never did it. The timing was in the event log the whole time.
