## §0 — BEFORE YOU LAUNCH ANYTHING

### `ds_option` IS NOT A COMMAND-LINE FLAG

**There is no `-ds_option`.** It lives in
`%LOCALAPPDATA%\GoldenRecomp\graphics.json`. **Every number in `103`-`106` was
measured at `1`, and the file currently says `2`** (`108` §3), so comparing a
new run against `106` §1's table without pinning it measures two changes at once.

```powershell
# Set ds_option back to 1 for the like-for-like runs.
$g = "$env:LOCALAPPDATA\GoldenRecomp\graphics.json"
Copy-Item $g "$g.bak-prerun" -Force
(Get-Content $g -Raw) -replace '"ds_option"\s*:\s*\d+', '"ds_option": 1' | Set-Content $g
Select-String -Path $g -Pattern 'ds_option|msaa_option|rr_option|rr_manual_value'
```

**That last line must show `ds_option: 1`, `msaa_option: "None"`,
`rr_option: "Manual"`, `rr_manual_value: 90`.** If `msaa_option` is anything but
`"None"`, stereo silently stops working — `43`.

> **THE MENU REWRITES THIS FILE.** If you visit the in-game graphics menu during
> any run, re-check it before trusting that run.
