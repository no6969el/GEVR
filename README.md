# GEVR

**GoldenEye. Native. In VR. Bring your own ROM.**

GEVR is a from-source PC port of *GoldenEye 007* for real OpenXR VR. You stand inside the game. You bring a USA GoldenEye ROM you own. The zip has no ROM and no HD texture pack.

**Latest is [vr456.1](https://github.com/no6969el/GEVR/releases/tag/vr456.1).** Download [GEVR-Beta-vr456.1-win64.zip](https://github.com/no6969el/GEVR/releases/download/vr456.1/GEVR-Beta-vr456.1-win64.zip).

## Install

1. Download [GEVR-Beta-vr456.1-win64.zip](https://github.com/no6969el/GEVR/releases/download/vr456.1/GEVR-Beta-vr456.1-win64.zip) from the [vr456.1 release](https://github.com/no6969el/GEVR/releases/tag/vr456.1). If you already have GEVR, hit **Update** in GevrRomStarter.
2. Unzip it.
3. Run `Start-GEVR.bat`. Point it at your USA `.z64` when it asks.
4. Put the headset on. Recenter with both thumbstick clicks.

Run the bat. A bare `goldeneye.exe` can skip the ROM cache update and leave VR input off.

No headset: run `Play-on-monitor.bat`.

The first launch after an update rebuilds the picture cache once from your ROM. Saves and GEVR Settings stay under `%LOCALAPPDATA%\GEVR`.
