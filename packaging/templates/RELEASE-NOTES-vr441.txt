GEVR Beta vr441
===============

From-source GoldenEye 007 in real OpenXR VR. Bring your own USA ROM.

This zip has no ROM. You supply a USA GoldenEye .z64 you legally own.

What changed since vr440
------------------------
The game binary is unchanged - vr440 and vr441 ship the same goldeneye.exe.
What changed is the boot script that turns features on.

vr440 booted the picture KEEP only. The chair features were in the binary the
whole time and the boot never switched them on, so bodies vanished, explosion
texture was wrong, and the aim / arm behaviour was not the tuned one. vr441
boots the full set:

- Bodies stay after a kill (up to 48)
- Explosion and fire draw with the right texture and byte order
- The tuned aim path: ADS sight, hit-mark mapping, ADS cull, vertex guard
- Correct floor height, so hands and gun sit where they should

Play
----
1. Unzip anywhere.
2. Headset: run Start-GEVR.bat
   Monitor / no headset: run Play-on-monitor.bat
3. Point it at your USA .z64.
4. In VR, recenter with both thumbstick clicks.

First time
  The first launch waits once while images prepare into
  %LOCALAPPDATA%\\GEVR\\cache, then you play.

Updating from an older Beta
  Keep the same .z64. Each cut carries a ship stamp, so the first
  launch after an update rebuilds that cache once automatically.
  You do not need to delete the cache folder by hand.

If the picture still looks wrong: delete %LOCALAPPDATA%\\GEVR and
run the bat again.

If anything goes weird
----------------------
If the world turns glitchy, empty, or you load into junk space after
finishing a level and waiting on the character / folder screen:
fully close the game and run Start-GEVR.bat again. Loading another
mission in the same process often stays broken.

Please file a report so we can fix it:
https://github.com/no6969el/GEVR/issues/new/choose

Include headset, OpenXR runtime, SteamVR on/off, HMD vs monitor,
Start-GEVR.bat yes/no, the map, and a log or short clip if you have
one. Do not upload your ROM.

Why older zips
--------------
- vr434 was pulled: ROM images were baked into goldeneye.exe.
- vr438 required your ROM but shipped a stripped VR boot.
- vr440 had the right picture but never turned the chair features on.
  Grab vr441.

Headset notes
-------------
Auto-Aim defaults OFF. Left stick moves the pause highlight in VR (was look-stick only).

In headset, B/Y opens pause and options. Tab on keyboard/monitor still works.

Pimax Crystal Super + SteamVR OpenXR, native PimaxXR, Quest 3 +
Virtual Desktop OpenXR.

72 / 80 / 90 Hz should work (default 90). Over 90 is still
beta-test territory. Please report issues.

Still rough
-----------
- Occasional crashes (file an Issue: headset, OpenXR runtime,
  SteamVR on/off, HMD vs monitor, Start-GEVR.bat yes/no)
- After a finished level + character / folder wait, next load can
  dump you in junk space until you fully quit and relaunch
- Dam crates can still pop in
- Dam water can look murky
- Glass bullet holes can be one-eye
- Local split-screen MP works.
