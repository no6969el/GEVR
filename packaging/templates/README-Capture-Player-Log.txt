GEVR - headset problem? Make a log
==================================

If your headset does not show the game, use this.

1. Download GEVR-Capture-Player-Log.zip from the GitHub release.
2. Open the zip. Copy GEVR-Capture-Player-Log.bat into your GEVR
   game folder (the same folder that has Start-GEVR.bat).
3. Put your headset on / start Virtual Desktop (or your usual PC VR).
   Quest: set OpenXR to Virtual Desktop.
4. Double-click GEVR-Capture-Player-Log.bat
5. Press a key when it asks. Let the game run until the problem
   shows, then quit the game.
6. Send gevr-player-log.txt to BarZ on Discord.

Do NOT send your Nintendo ROM file.

In a good log, near the top you should see GETV_VR=1 and GETV_XR_PLAY=1.
If those are blank, the game never tried VR.
