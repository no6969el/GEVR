GEVR Beta vr439
===============

From-source GoldenEye 007 in real OpenXR VR. Bring your own USA ROM.

This zip has no ROM. You supply a USA GoldenEye .z64 you legally own.

Play
----
1. Unzip anywhere.
2. Pick a launcher:
   - Headset: Start-GEVR.bat (same picture as the vr434 quality KEEP)
   - Monitor / no headset: Play-on-monitor.bat (flat, no OpenXR)
3. Point it at a USA GoldenEye .z64 you own.
4. In VR, recenter with both thumbstick clicks.

First time
----------
The first launch waits once while images prepare into
%LOCALAPPDATA%\GEVR\cache, then you play.

Updating from an older Beta
---------------------------
Keep the same .z64. Each cut carries a ship stamp, so the first
launch after an update rebuilds that cache once automatically.
You do not need to delete the cache folder by hand.

If the picture still looks wrong, delete %LOCALAPPDATA%\GEVR and
run the bat again.

Why this zip (not vr420 / vr434 / vr438)
----------------------------------------
vr420, vr434, and vr438 stay on GitHub for history. Their zip
assets were removed.

vr438 had the ROM starter, but the VR boot was stripped and
looked like an old build. Grab this vr439 zip instead.

vr434 was pulled: ROM images were baked into goldeneye.exe so it
could boot without a ROM.

Headset play uses the same quality KEEP as the happy vr434
picture (XR stereo source, SrcFbo, SS3, skymesh / skyscissor,
playspace, recenter chord, MSGSCALE 434). Only the ROM /
file-backed image path is new.

Headset notes
-------------
Pimax Crystal Super + SteamVR OpenXR, native PimaxXR, Quest 3 +
Virtual Desktop OpenXR.

72 / 80 / 90 Hz should work (default 90). Over 90 is still
beta-test territory. Please report issues.

Still rough (honest)
--------------------
- Occasional crashes. File an Issue with headset, OpenXR runtime,
  SteamVR on/off, HMD vs monitor, and which bat you used.
- Dam crates can still pop in.
- Dam water can look murky.
- Glass bullet holes can be one-eye.
- Local split-screen multiplayer works on a monitor. A LAN /
  same-network multiplayer add-on is later.

https://github.com/no6969el/GEVR/issues/new/choose

Do not upload your ROM.
