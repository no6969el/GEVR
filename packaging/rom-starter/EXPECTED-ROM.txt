GEVR Beta - expected USA GoldenEye ROM (BYO-ROM)
================================================

You must supply a **USA** GoldenEye 007 cartridge dump you legally own.

Typical GoodN64 name:
  GoldenEye (U) [!].z64

This zip does **not** contain:
  - any .z64 / .n64 / .v64 file
  - EEPROM saves from the cartridge

The ROM starter validates your file, then extracts image data into:
  %LOCALAPPDATA%\GEVR\cache\<your-ROM-SHA-256>\

That folder holds combined.bin, a ready marker, and ship.txt (matches the Beta tag, e.g. vr438).
First prepare can take a bit. Later launches with the same zip and same ROM skip that wait.
After a public zip update, GEVR rebuilds this cache once from your same ROM if the stamp changed.
You do not need to delete the cache folder yourself. Wipe %LOCALAPPDATA%\GEVR only if
something looks wrong, then run Start-GEVR.bat again.

After a successful prepare step, goldeneye.exe loads textures from that cache (file-backed images).

If prepare fails, check that:
  - the ROM is the USA release (not EU/JP)
  - the file is a clean dump (not truncated)
  - antivirus is not blocking GevrRomStarter.exe or gevr_prepare.exe

Owner: refresh SHA-256 and byte size here after verifying on SimRig (do not commit ROM bytes).
