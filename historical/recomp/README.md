# Historical — recomp-host patches

These MIT patches were written for the early headset experiments that attached
to [cblock85/GoldenEye64Recomp](https://github.com/cblock85/GoldenEye64Recomp)
(GPL-3.0). They compile only inside that tree.

They are **not** the active GEVR path. Active work is native from-source
(see the root README). Kept here for provenance, not as build instructions.
